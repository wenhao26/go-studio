## 1. 测试分层策略

| 层 | 方法 | 覆盖对象 | 工具 |
|---|---|---|---|
| 单元 | 表格驱动 | classifier 规则、状态机转换、冲突命名、单位/耗时格式化、净化 | `go test` |
| 集成 | `t.TempDir()` 真实文件树 + 故障注入 | scanner 遍历、organizer 移动/撤销 | `go test` + `fsx` 假实现 |
| 存储 | 临时 DB | 批量写、分页、Migration、保留清理 | `go test` |
| 并发 | `-race` | scanner/task/organizer 并发面 | `go test -race` |
| 手动 | 验收清单（§6） | 前端交互、性能、稳定性 | 人工 |

时间依赖通过注入 Clock，**禁止 `time.Sleep` 等待**（`testing.md` §5）。

| 范围 | 门槛 |

| 工具/基础（格式化、净化、fsx 等） | ≥85% |

## 3. 表格驱动测试清单（必测项）

### 3.1 分类（`classifier`）

| 用例 | 输入 | 期望 |
|---|---|---|
| PRD 示例 1 | `合同.pdf` | 工作 95%（原因：命中关键词: 合同） |
| PRD 示例 2 | `发票2025.pdf` | 财务 95% |
| PRD 示例 3 | `photo.jpg` | 图片 60% |
| PRD 示例 4 | `README` | 其他 0% |
| 多关键词 | `项目方案.docx` | 工作（100 截顶） |
| 路径+关键词 | `D:/合同/a.pdf` | 工作 80% |
| 零命中 | 任意无规则文件 | 其他 0% |
| 大小写 | `INVOICE.PDF` | 财务 |
| 中文路径 | 路径含 `发票` | 财务 |
| 无扩展名 | `concept` | 依关键词或 其他 |
| 封顶 | 多命中 | 置信度 ≤100 |

### 3.2 状态机（`task`）

合法：`pending→running`、`running→{completed,failed,canceled}`、`pending→canceled`。
非法：`completed→running`、`failed→completed`、`canceled→running`、任何到达 `paused` → 必须拒绝。

### 3.3 冲突命名（`organizer`）

| 场景 | 期望 |
|---|---|
| 目标不存在 | 原名 |
| 原名存在 | `名 (1).ext` |
| `(1)` 也存在 | `(2)`… |
| 超过上限 | 该条 failed |

### 3.4 格式化

| 项 | 边界 |
|---|---|
| 大小 | 0 / 1023 B / 1024 B / 1 MB / 1 GB / 溢出（`int64`） |
| 耗时 | <1s / =1s / >1s |
| 千分位 | Bytes 整数带千分位 |

### 3.5 净化（SEC-5）

含控制字符/ANSI/`\r`/`\n` 的文件名 → 写日志/事件前剥离，防日志注入与渲染异常。

### 3.6 存储（`storage`）

批量 500 边界（499/500/501）、分页首/中/末/越界、Migration 幂等、保留清理（>20 次）。

## 4. 集成测试（`t.TempDir`）

| 场景 | 断言 |
|---|---|
| 正常扫描 | 文件数/目录数/大小/跳过数正确 |
| 权限拒绝 | 跳过并计数，不中断 |
| 符号链接/junction | 不下潜、不计主计数、计入跳过 |
| 大文件开关 | `>1GiB` 跳过并计数 |
| 黑名单目录 | 始终跳过 |
| 整理正常 | 文件出现在 `<根>/FilePilot整理/<类别>/`，内容未变（哈希/大小比对） |
| 同名冲突 | 生成新名，**原文件未被覆盖** |
| 占用失败 | 该条 failed，其余继续 |
| 目标目录不可写 | 零移动 |
| 取消扫描 | 部分统计保留，不进预览/整理 |
| 取消整理 | 已完成保留，报告部分完成 |
| 撤销 | 全部成功项回移；原路径占用跳过；重复撤销报错 |

> 「零删除、零覆盖」为**硬断言**：整理前后对目标目录既有文件逐一比对，确保未被改写/删除。

## 5. 性能基准

| 指标 | 目标 | 方法 |
|---|---|---|
| 扫描吞吐 | SSD 10 万文件 ≤60s（默认并发） | 固定数据集人工基准，记录环境/数据 |
| 整理吞吐 | 10 万文件移动 ≤60s | 顺序 rename 基准 |
| 内存 | 峰值不随文件数线性暴涨 | 10 万文件扫描观察 RSS |
| UI 不卡顿 | 扫描/整理期间可交互 | 事件节流契约 + 手动观察 |

基准结果记录到项目 `README.md`。

## 6. 手动 UI 验收清单（R-8：前端无自动化测试）

```text
[ ] P1 未选目录点开始 → 提示「请选择扫描目录后继续」，不创建任务
[ ] P1 取消目录选择 → 提示「目录选择失败 / 用户取消操作」
[ ] P1 最近目录 ≤5、去重、最近在前
[ ] P1 非法并发数 → 立即报错，不静默钳制
[ ] P2 扫描进度不出现总数/百分比/ETA
[ ] P2 三类日志实时滚动且不冻结；日志区上限 500 行
[ ] P2 日志丢弃时出现「已丢弃 N 条明细」
[ ] P2 取消按钮 → 任务 canceled + 部分结果标注
[ ] P3 汇总计数与详情一致；详情分页 100/页
[ ] P3 改类别后置信度显示「手动」，原因「用户手动指定」
[ ] P3 排除/恢复排除生效
[ ] P4 整理前二次确认（数量 + 目标目录）；取消 = 无写操作
[ ] P4 确定型进度 x/y + 百分比
[ ] P4 失败明显示可定位
[ ] P4 撤销前二次确认；重复撤销提示「该整理已撤销」
[ ] 所有任务进行中可返回；空态文案齐全
```
